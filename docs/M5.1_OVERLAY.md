## Rebuild & test
    docker compose build backend worker
    docker compose up -d
    sh scripts/m51_smoke.sh

Spine assertions (the two that matter):
- `PERMFAIL!` question → worker logs exactly `attempt 1/…` then DLQ; NO
  `attempt 2/` or `3/`; a `[classify] NON-TRANSIENT` line is present.
- `FAIL!` question → worker logs `attempt 1/2/3` then DLQ (transient path
  untouched).

Stage 3 (NO_DATA measured_absence end-to-end) is SKIPPED unless you export
`NODATA_AOI` with an AOI where LiCSBAS runs but yields zero valid pixels after
inversion (water / dense vegetation / steep terrain — e.g. a La Spezia
harbour+hills box). When set, it asserts the query finalizes `done` (an answer,
not `failed`), the worker shows a single attempt (exit 0, no retry), and the
result.json carries `status:"no_data"` / `no_data_reason:"measured_absence"`.
